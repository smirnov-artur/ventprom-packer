# VentProm Packer — 3D-упаковка воздуховодов в транспорт

Живое демо: https://smirnov-artur.github.io/ventprom-packer/

Спецификация воздуховодов раскладывается по кузову фуры, «Газели» или КАМАЗа.
Алгоритм упаковки (beam search) выполняется целиком в браузере — серверная часть
не используется. Данные в демо тестовые.

Разбор проекта: https://smirnov-artur.github.io/works/
